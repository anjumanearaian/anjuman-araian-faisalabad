## 1. Project Nature

This project should not be developed as a static website only. It should be developed as a dynamic, admin-controlled web platform where Anjuman e Araian Faisalabad can manage content, members, business profiles, events, sponsors, discount offers, matrimonial inquiries, leadership updates and future website updates through a simple admin panel.

The admin panel should be easy to use and should not require coding knowledge.

## 2. Public Website

The public website should include the following sections:

* Home Page
* About Us
* Vision & Mission
* History
* Constitution / Memorandum PDF viewer or download section
* President Message
* General Secretary Message / Profile
* Founders / Patrons
* Ex-Presidents
* Cabinet Members, preferably with tree or structured hierarchy
* Executive Members
* Advisory Board
* Events, with posting and updating option
* Media, with posting and updating option
* Overseas Members
* Contact Page
* News / Announcements, with posting and updating option
* Matrimonial Page with a simple form and WhatsApp contact/attachment option
Note: Admin will be able to post and change content for events, news/ announcements


## 3. Dynamic CMS / Admin Panel

The admin panel should allow authorized admins to add, edit, publish, unpublish, approve, reject and delete content without touching code.

Admin should be able to manage:


* News and announcements
* Events


The admin panel should remain simple and practical, similar to an “Add New / Edit / Publish / Approve / Reject” system.

## 4. Member Portal

The system should include:

* Member registration form
* Member login
* Profile management
* Document upload
* Admin approval/rejection
* Member status management
* Auto-generated member profile after approval

Admin should decide whether a member profile is public, private, active, inactive, published or unpublished.

## 5. Family Information Section

The member registration form should include a family information section, where required by Anjuman.

This section may include:

* Father’s name
* Family / branch details
* Spouse name, if required
* Children details, if required
* Family contact number
* City / area
* Emergency contact person
* Emergency contact number
* Relationship with emergency contact

This information should remain private by default and should only be visible to authorized admin users unless Anjuman specifically decides otherwise.

## 6. WhatsApp Contact and Messaging Integration

Anjuman will provide its official WhatsApp number.

The website should include WhatsApp contact and messaging options, including:

* WhatsApp button on the website
* Applicant WhatsApp number visible in the admin dashboard

WhatsApp numbers should not be displayed publicly unless the admin specifically allows it.

## 7. Business Community / Business Directory Module

A separate Business Community / Business Directory section should be developed.

Any member or business owner should be able to submit a business profile through a simple public form, similar to a Google Form style, but connected with the website admin panel.

The business profile form should include:

* Business name
* Owner / member name
* Business category
* City
* Address
* Phone / WhatsApp
* Email
* Website
* Social media links
* Logo upload
* Business description
* Products / services
* Discount offer for Anjuman members
* Sponsorship / listing package
* Payment proof upload

No business profile should be published automatically. All submissions should first go to the admin dashboard for review and approval.


## 10. Matrimonial Page

The website should include a simple Matrimonial Page for the community.

This page should not be complex in the first phase. It may include a simple form, similar to a Google Form style, where users can submit their matrimonial inquiry or basic details.

The matrimonial form/page should include:

* Name
* Gender
* Age
* City
* Education
* Profession
* Family background, if required
* Contact number / WhatsApp number
* Basic requirement or proposal details
* Document/photo upload option, if required
* WhatsApp attachment/contact option

All matrimonial submissions should remain private and should only be visible to authorized admin users.

No matrimonial profile or inquiry should be published publicly without admin approval and specific consent.


Payment may initially be handled manually through bank transfer, Easypaisa/JazzCash or receipt upload.

Admin should be able to mark payment status as:

* Pending
* Received
* Verified
* Rejected

Admin should be able to approve or reject member applications, business profiles, discount offers, sponsorship requests and matrimonial submissions.


## 14. Roles and Access Control

The system should include role-based admin access, such as:

* Admin


Each role should have access only to relevant sections.
