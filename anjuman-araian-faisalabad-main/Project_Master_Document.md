# Anjuman-e-Araian Faisalabad Digital Platform

## Project Overview

A bilingual community management platform for Anjuman-e-Araian
Faisalabad.

## Technology Architecture

-   Frontend: React + TypeScript + Vite
-   Backend: Node.js + Express
-   ORM: Prisma
-   Database: PostgreSQL

## Core Modules

-   Member Management
-   Committee Management
-   Events Management
-   Gallery
-   Welfare Activities
-   Admin Dashboard
